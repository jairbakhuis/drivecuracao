# Drive Curaçao Google Ads starter plan

This is the first paid-search plan for Drive Curaçao. Keep the first campaign small, measure real booking requests, then scale what works.

## Goal

Drive high-intent visitors to request a rental car from Drive Curaçao.

Primary landing page:

- `https://drivecuracao.com/cars`

Primary conversion:

- A submitted car request / booking request.

## Starter budget

Start small and learn before scaling:

- **US$10–20 per day** for the first 7 days.
- Review search terms, clicks, and booking requests before increasing budget.
- Pause keywords that spend without producing requests.

## Campaign structure

Campaign name:

- `DriveCuracao - Search - Car Rental`

Recommended campaign type:

- Google Search

Networks:

- Search Network only at first.
- Do not enable Display Network for the first test.

Bidding:

- Start with Maximize Clicks if no conversion tracking is ready yet.
- Switch to Maximize Conversions once request/conversion tracking is working.

## Location targeting

Start with travelers most likely to search before/during a Curaçao trip:

- Netherlands
- Curaçao
- United States
- Canada
- Aruba and Bonaire, optional test

Use **Presence or interest** carefully. If budget is tight, prefer people in or regularly in target locations plus people searching for Curaçao terms.

## Conversion tracking

Before scaling the budget, track at least one conversion:

- Booking/request submitted successfully.

If that is not ready yet, start manually by comparing:

- Google Ads clicks
- Website request emails/reservations
- Cost per request

## First-week routine

Daily checks:

1. Spend
2. Clicks
3. Search terms
4. Bad queries to add as negative keywords
5. Any request/booking emails generated
6. Cost per request if conversion tracking is available

After 7 days:

- Keep keywords that produced requests.
- Pause keywords with spend and no useful traffic.
- Add SEO pages for search terms that look promising.
